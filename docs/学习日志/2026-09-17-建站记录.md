# 2026-09-17 建站：把这个站搭起来

把 GitHub Pages 上那个只有一行字的占位页，换成了一个真正的笔记站。

- 站点用 **VitePress** 生成，源码放在仓库的 `docs/` 目录

## 踩到的坑

**1. GitHub 用户名到底能不能叫 Junxiii？**

不能。GitHub 的 `Username`（登录名）是**全局唯一**的，`junxiii` 在 2020 年就被别人注册走了，永远抢不到。

但 GitHub 有另一个字段 `Name`（昵称），这个**不要求唯一** —— 所以昵称写 `Junxiii` 完全没问题，别人打开主页看到的就是 Junxiii。最后登录名用了 `Foolscape`，昵称保持 `Junxiii`，两个都保住了。

**2. 仓库为什么不能改名成 Junxiii？**

GitHub Pages 的「用户主页」有个硬性规则：仓库必须**严格叫** `<用户名>.github.io`，才能拿到 `https://<用户名>.github.io/` 这个干净的根域名。改成别的名字，网址就会掉成 `https://foolscape.github.io/仓库名/`，多一层路径，纯亏。

**3. npm 装不上**

`npm install` 报 `EPERM`，因为默认缓存目录在 `C:\Users\...\npm-cache`，当前环境不允许写工作区以外的地方。加上 `--cache` 指到项目里就好了：

```bash
npm install --cache ./.npm-cache
```

## 学到了什么

- Git 的提交历史本身就是一份「学习过程档案」，`git log` 能看出自己哪几天在认真干活
