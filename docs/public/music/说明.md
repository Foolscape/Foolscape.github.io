# 背景音乐放这里

把音频文件（推荐 `.mp3`，体积最小）放进这个文件夹，然后打开
`docs/.vitepress/theme/components/BgmPlayer.vue`，把文件名填进 `tracks` 数组：

```js
const tracks = [
  '/music/bgm.mp3'
]
```

- 路径以 `/music/` 开头（`docs/public/` 会映射到网站根目录）
- 填**一首** → 单曲循环
- 填**多首** → 按顺序自动切换

## 几个注意事项

**体积**：一首 4 分钟的 MP3 在 128 kbps 下约 3.8 MB。放进网站后每次点播放都会下载它。
用 96 kbps 能压到约 2.9 MB，听感差别不大。

**版权**：这个仓库是**公开**的，放进来等于公开分发。商业歌曲理论上有收到下架通知、
甚至整个仓库被禁用的风险 —— 你的笔记会跟着一起没。建议用无版权（CC0 / 公共领域）音源：

- Pixabay Music
- Free Music Archive（筛选 CC0 / CC-BY）
- Incompetech（Kevin MacLeod，署名即可商用）

**自动播放做不到**：浏览器一律拦截未经用户操作就出声的音频，这是硬规定。
所以做成了「点右下角按钮开始播」，之后全站切页面不中断。
