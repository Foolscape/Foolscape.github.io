## 为什么建这个站

上课听懂了，过两周就忘了。手写的笔记堆在本子里，期末翻不到；课件散在十几个文件夹里，找一份真题要翻半天。

所以我把笔记搬到这里：

1. **纯文本**：全部是 Markdown，用 Git 管理，十年后还能打开，不依赖任何笔记软件。
2. **按课程组织**：一门课一个文件夹，结构化可检索，期末复习直接按目录过一遍。
3. **手写也不丢**：手写扫描件、拍照的板书以 PDF/图片形式归档，和对应章节放在一起。
4. **顺便练工具**：写笔记的同时熟悉 Markdown、Git、CI/CD —— 这些本身就是计算机专业该会的东西。
