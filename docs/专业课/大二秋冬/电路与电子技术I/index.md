## 复习要点

> 期末前把最容易忘、最容易考的点挪到这里，比翻整本书快得多。

- 节点电压法列方程时，**互导项恒为负**，这是最容易写错符号的地方
- 戴维南等效的关键是求开路电压和等效电阻，含受控源时等效电阻要用**外加电源法**
- 一阶电路三要素法：`f(t) = f(∞) + [f(0₊) − f(∞)]·e^(−t/τ)`，注意 `f(0₊)` 要用换路定则
