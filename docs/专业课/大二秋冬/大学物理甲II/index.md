## 复习要点

> 期末前把最容易忘、最容易考的点挪到这里。

- **高斯定理**：只对**对称**场好用，选高斯面时让 `E` 垂直于面或平行于面
- **安培环路定理**：同样要求对称性，注意电流的正负号按右手螺旋判定
- **位移电流**：`I_d = ε₀ dΦ_E/dt`，它是麦克斯韦方程组的核心补丁
- **杨氏双缝**：条纹间距 `Δx = Dλ/d`，与波长成正比、与缝距成反比
- **光程差与半波损失**：反射发生在**光疏到光密**界面时才有半波损失，最容易漏
- **光电效应**：`hν = W + E_k`，与光强无关、与频率有关 —— 经典波动说解释不了
- **德布罗意波长**：`λ = h/p`，注意用相对论动量还是经典动量要看速度
