## 复习要点

> 期末前把最容易忘、最容易考的点挪到这里。

- **柯西–黎曼方程**：`∂u/∂x = ∂v/∂y`，`∂u/∂y = −∂v/∂x`，这是判断解析的充要条件（加偏导连续）
- **解析 ⇔ 可导**，且解析函数有任意阶导数 —— 这是实变函数里没有的性质
- **柯西积分公式**：`∮ f(z)/(z−z₀) dz = 2πi·f(z₀)`，前提是 `f` 在区域内解析
- **洛朗级数**是留数的基础，注意**展开中心必须是奇点**才能直接读出 `c₋₁`
- **留数定理**：`∮ f dz = 2πi·Σ Res`，算实积分时关键是选对**围道**并证明弧上积分为 0
- **傅里叶变换 vs 拉普拉斯变换**：拉氏变换多了收敛因子 `e^(−σt)`，所以能处理增长更快的函数；解微分方程时拉氏更常用，因为自带初值
