## 新增一门课怎么做

**方法一（推荐）**：直接在 `docs/专业课/` 下新建一个文件夹，比如 `操作系统`，然后在里面写 `.md` 笔记。侧边栏会自动出现这门课。

**方法二**：把手写扫描件、课件 PDF 丢进 `docs/public/资料/操作系统/`，构建时会自动建好 `操作系统` 这门课和一个「资料下载」页。

两种方法都不需要改任何配置文件 —— 目录、导航、侧边栏、搜索索引全部自动生成。

## 目录约定

```text
docs/专业课/<课程名>/
  index.md          ← 课程总览（没有会自动生成）
  第01章-xxx.md     ← 章节笔记，按文件名排序
  资料下载.md        ← 自动生成，不要手动改
docs/public/资料/<课程名>/
  课件.pdf          ← 原始资料，会自动汇总到「资料下载」页
```

> 文件名的排序规则：`index.md` 永远在最前，「资料下载」永远在最后，中间的按**中文数字序**排 —— 所以用 `第01章`、`第02章` 这样补零命名，顺序最稳。
