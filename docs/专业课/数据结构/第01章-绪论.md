# 第 01 章 绪论

## 1.1 数据结构的基本概念

**数据**：能被计算机识别、存储和处理的符号集合。

**数据元素**：数据的基本单位，也叫记录。一个数据元素可以由若干**数据项**组成。

**数据结构**：互相之间存在一种或多种特定关系的数据元素的集合。包含三个方面：

1. **逻辑结构** —— 数据元素之间的抽象关系，与存储无关
   - 线性结构：线性表、栈、队列、串
   - 非线性结构：树、图、集合
2. **存储结构（物理结构）** —— 逻辑结构在计算机中的表示
   - 顺序存储：用连续的存储单元，逻辑相邻则物理相邻
   - 链式存储：用指针表示逻辑关系，物理上可以不连续
   - 索引存储、散列存储
3. **数据的运算** —— 增删改查等操作的实现

> 常考：**逻辑结构与存储无关**。同一个逻辑结构可以有多种存储实现，比如线性表既能用数组也能用链表。

## 1.2 算法与算法分析

**算法**的五个特性：

| 特性 | 含义 |
| --- | --- |
| 有穷性 | 有限步之内结束，且每一步都可行 |
| 确定性 | 相同输入必得相同输出，无二义性 |
| 可行性 | 每一步都能用基本运算实现 |
| 输入 | 零个或多个输入 |
| 输出 | 至少一个输出 |

### 时间复杂度

**大 O 记号**描述的是**增长量级**，不是精确运行时间。常见复杂度由小到大：

```text
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
```

分析时的实用法则：

- **只看最高阶项，忽略系数**：`3n² + 5n + 7` → `O(n²)`
- **顺序执行相加，循环嵌套相乘**
- **循环变量成倍变化时**，循环次数是 `log n`：

```c
// 时间复杂度 O(log n)
int i = 1;
while (i <= n) {
    i = i * 2;
}
```

### 一个容易做错的例子

```c
// 求下面这段代码的时间复杂度
for (int i = 0; i < n; i++) {
    for (int j = i; j < n; j++) {
        x++;
    }
}
```

内层执行次数是 `n + (n-1) + ... + 1 = n(n+1)/2`，所以是 `O(n²)`。

> 陷阱：如果内层写成 `for (int j = 0; j < i; j++)`，结果同样是 `O(n²)` —— 别看到 `j < i` 就以为是 `O(n log n)`。

## 1.3 空间复杂度

只统计**辅助空间**，不包含输入数据本身占用的空间。

- 原地（in-place）算法：`O(1)`
- 递归算法的空间复杂度 = **递归深度**

> 易错点：递归求阶乘的空间复杂度是 `O(n)`（递归栈深度），不是 `O(1)`。

## 本章小结

- 逻辑结构 vs 存储结构，别混
- 大 O 只看最高阶，会写递推式
- 递归的空间复杂度看递归深度
