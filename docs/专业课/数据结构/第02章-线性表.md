# 第 02 章 线性表

## 2.1 线性表的定义

线性表是 n 个数据元素的**有限序列**，除首元素外每个元素有且仅有一个前驱，除尾元素外每个元素有且仅有一个后继。

## 2.2 顺序存储：顺序表

用一组**地址连续**的存储单元依次存放。逻辑相邻 ⇔ 物理相邻。

**随机访问**：第 i 个元素的地址可以直接算出来，所以按下标访问是 `O(1)`。

```c
// 顺序表插入：在第 i 个位置插入 e
// 时间复杂度 O(n)，平均移动 n/2 个元素
bool ListInsert(SqList *L, int i, int e) {
    if (i < 1 || i > L->length + 1) return false;  // 位序不合法
    if (L->length >= MaxSize) return false;        // 存满了
    for (int j = L->length; j >= i; j--)           // 从后往前挪，防止覆盖
        L->data[j] = L->data[j - 1];
    L->data[i - 1] = e;
    L->length++;
    return true;
}
```

> **易错点**：挪动必须**从后往前**。如果从前往后，`data[i-1]` 会在被读取前就被覆盖掉。

## 2.3 链式存储：单链表

用指针表示逻辑关系，物理上可以不连续。每个结点包含**数据域**和**指针域**。

### 头结点到底要不要

| 方式 | 第一个结点的处理 | 插入/删除第一个结点 |
| --- | --- | --- |
| 带头结点 | 统一，头指针永远指向头结点 | 与其他位置代码一致 |
| 不带头结点 | 需要特判 | 需要修改头指针，代码分叉 |

**考试时优先写带头结点的版本**，代码更短且不易出错。

```c
// 按位查找：返回第 i 个结点（带头结点）
// 时间复杂度 O(n)
LNode *GetElem(LinkList L, int i) {
    if (i < 0) return NULL;
    LNode *p = L;              // 从头结点开始
    int j = 0;
    while (p != NULL && j < i) {
        p = p->next;
        j++;
    }
    return p;                  // i = 0 时返回头结点
}
```

## 2.4 两种存储结构对比

| 操作 | 顺序表 | 单链表 |
| --- | --- | --- |
| 按位查找 | `O(1)` | `O(n)` |
| 按值查找 | `O(n)` | `O(n)` |
| 插入（已知前驱） | `O(n)` 需挪元素 | `O(1)` 只改指针 |
| 插入（不知前驱） | `O(n)` | `O(n)` 要先找前驱 |
| 删除（已知前驱） | `O(n)` | `O(1)` |
| 空间 | 需预分配，可能溢出 | 动态分配，有指针开销 |

> 关键结论：链表「插入删除快」的前提是**已经拿到了前驱结点**。如果只给了位序，还是要先 `O(n)` 找过去。

## 2.5 常见变体

- **双链表**：多一个 `prior` 指针，找前驱变 `O(1)`，但插入删除要改四个指针
- **循环链表**：尾结点指向头结点。判空条件是 `L->next == L`（带头结点）
- **静态链表**：用数组模拟指针，`next` 存的是数组下标。适合不支持指针的语言

## 本章小结

- 顺序表随机访问快，链表插入删除快（前提：已定位前驱）
- 顺序表插入要**从后往前**挪
- 带头结点能统一边界情况，考试优先写
