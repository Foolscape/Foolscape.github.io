## 复习要点

> 期末前把最容易忘、最容易考的点挪到这里。

- **先化标准形**：一阶线性方程通解公式 `y = e^(−∫P dx)·(∫Q·e^(∫P dx) dx + C)` 只对 `y' + P(x)y = Q(x)` 成立，用之前必须先整理成这个形式
- **伯努利方程** `y' + P(x)y = Q(x)yⁿ` 用换元 `z = y^(1−n)` 化成线性；注意 `n = 0` 或 `n = 1` 时它本来就是线性，不用换元
- **全微分方程** `M dx + N dy = 0` 的判据是 `∂M/∂y = ∂N/∂x`；不满足时找**积分因子**，优先试只含 `x` 或只含 `y` 的
- **存在唯一性定理**：李普希茨条件是**充分不必要**条件；皮卡迭代构造出的是一致收敛的函数列，这是证明的核心
- **待定系数法求特解**：形式由 `f(x)` 定，但**必须检查是否与齐次解重复** —— 重复要乘 `x^k`，这是最高频的失分点
- **特征根**：重根要在通解里补 `x`、`x²`……；共轭复根 `α±βi` 对应 `e^(αx)(C₁cos βx + C₂sin βx)`
- **线性方程组**：先求特征值，再定特征向量；`Φ(x) = e^(A(x−x₀))` 是标准基解矩阵
- **稳定性**：第一方法看雅可比矩阵特征值的实部符号；第二方法（李雅普诺夫）要会构造 `V` 函数
