## 怎么选

| 想要 | 推荐 |
| --- | --- |
| 小尺寸最清楚、最稳 | **1**（粗体 J） |
| 一眼知道是中文站、有个人识别度 | **2**（峻） |
| 一看就是「笔记站」 | **3**（笔记纸） |
| 呼应站内的「章节进度」概念 | **4**（对勾） |

告诉我编号就行。如果想换配色（不用橙色、要纯色不要渐变、要深色底），也一起说。
